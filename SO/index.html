BIOS / UEFI: el primer código que se ejecuta, antes de que exista el sistema

Es la losa más baja de la torre y, paradójicamente, la primera en correr: vive en una flash SPI de la placa y se ejecuta al salir del reset, antes de que haya kernel, procesos o usuario. Las once tarjetas se desarrollan por dentro con dos ejemplos cada una: el técnico (POST y códigos al puerto 80, la flash SPI y las etapas del firmware, variables UEFI autenticadas en NVRAM y efivarfs, el Boot Manager con BootOrder/Boot####, Secure Boot con PK · KEK · db · dbx, el TPM y el arranque medido, el memory training, las tablas ACPI y el namespace, SMBIOS/DMI con dmidecode, Option ROM y GOP, y las actualizaciones por UpdateCapsule con recuperación) y el cotidiano (la pantalla de F2/Del, el pitido al prender, la PC que no arranca desde el pendrive, el “Secure Boot violation”, la hora que se resetea, el equipo que queda ladrillo tras una actualización de BIOS). Las once capas anteriores conservan todas sus descripciones completas.
