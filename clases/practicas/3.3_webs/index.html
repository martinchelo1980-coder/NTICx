⚙️ El flujo de datos: Entrada → Procesamiento → Salida

Toda actividad en la web sigue el mismo camino. Vos escribís o tocás algo (entrada), la computadora y el servidor trabajan con esos datos usando la CPU (calcula) y la memoria RAM (guarda lo que está en uso), y finalmente ves el resultado en pantalla (salida). Lo que queda guardado para siempre va al almacenamiento (disco, SSD o nube).

📥 Entrada

Teclado, mouse, micrófono, cámara o un clic en un enlace.

🧠 Procesamiento

CPU + memoria RAM: ejecutan instrucciones y transforman los datos.

📤 Salida

Pantalla, parlantes, impresora: el resultado que percibís.

💾 Almacenamiento

Disco, SSD, pendrive o nube: la información persiste.
