Concepto clave

¿Qué es un Sistema Informático?

Es un conjunto de elementos que trabajan en equipo para recibir, procesar, guardar y entregar información. Para que exista, hacen falta tres componentes:

🔩

HARDWARE

Todo lo que podés tocar: chips, cables, teclado, pantalla.

CPU · RAM · mouse · SSD

🧠

SOFTWARE

Los programas e instrucciones: no se tocan, se ejecutan.

Windows · WhatsApp · juegos

👤

HUMANWARE

Las personas: quienes usan, programan o reparan el sistema.

vos · técnicos · programadores

💡 Ejemplo cotidiano: vos (humanware) usando WhatsApp (software) en tu celu (hardware) para mandar un audio.

🗂️ Memoria RAM

Random Access Memory · memoria de trabajo

  • ⚡ Volátil: al apagar la compu, se borra.
  • ✍️ Se lee y escribe todo el tiempo.
  • 🚀 Muy rápida: la CPU la usa como mesa de trabajo.
  • 📏 Se mide en GB: hoy lo normal es 8 o 16 GB.

📜 Memoria ROM

Read Only Memory · firmware / BIOS

  • 🔒 No volátil: conserva los datos sin energía.
  • 📖 Principalmente de solo lectura.
  • 🚼 Guarda la BIOS/UEFI que arranca la compu.
  • 🐢 Más lenta, pero siempre firme.

Idea central

🔢 ¿Qué es el Sistema Binario?

Nuestro sistema decimal usa 10 dígitos (0-9). El binario usa solo dos: el 0 y el 1. Cada dígito se llama bit. ¿Por qué? Porque por dentro la compu tiene millones de interruptores microscópicos (transistores) con dos estados eléctricos: con corriente (1) o sin corriente (0). 💡

1 bit
= un 0 ó un 1
1 byte
= 8 bits = 256 combinaciones

Combinando bits, la compu representa números, letras, colores y sonidos. Ejemplo del código ASCII:

A = 65 B = 66 a = 97 0 = 48 ! = 33

(Aproximación ASCII básico: con acentos o emojis cada carácter puede ocupar más bytes.)

Del mundo real al 0 y 1

🎛️ Digitalización

El mundo real es analógico: continuo (la voz, la luz, el movimiento). Digitalizar es convertir esas señales en números binarios mediante tres pasos:

  1. 1.Muestrear: medir la señal miles de veces por segundo. 📸
  2. 2.Cuantificar: asignar un número a cada medición. 🔢
  3. 3.Codificar: escribir esos números en binario. 💾

Así tu canción favorita, una selfie o este mismo texto son, en el fondo, ¡millones de ceros y unos! ✨

    Módulo 2 · Arquitectura y Componentes de la Computadora

    La CPU (Unidad Central de Procesamiento)

    Es el "cerebro" del sistema: ejecuta instrucciones, realiza cálculos y coordina los demás componentes. Su velocidad se mide en GHz y su capacidad de trabajo paralelo, en núcleos. Internamente se divide en:

    • UC (Unidad de Control): "directora de orquesta". Busca las instrucciones en la memoria, las interpreta y ordena su ejecución. No calcula: coordina.
    • ALU (Unidad Aritmético-Lógica): realiza las operaciones matemáticas (+, −, comparaciones) y lógicas (AND, OR, NOT).
    • Registros: memoria ultrarrápida interna que guarda los datos que se están usando en el instante.

    Memorias RAM y ROM

    CaracterísticaRAM (Random Access Memory)ROM (Read Only Memory)
    VolatilidadVolátil: se borra al apagar.No volátil: conserva datos sin energía.
    UsoLectura y escritura constantes.Principalmente lectura.
    FunciónMesa de trabajo temporal de la CPU.Guarda el firmware (BIOS/UEFI) de arranque.
    VelocidadMuy rápida.Más lenta, pero permanente.
    Capacidad típica8 a 32 GB.Pocos MB.

    Es la placa de circuitos principal: interconecta y comunica todos los componentes (CPU, memorias, discos, puertos y tarjetas de expansión) y distribuye la energía.

    Módulo 3 · Características del Computador y Periféricos

    Velocidad de procesamiento

    • GHz (gigahertz): miles de millones de ciclos de reloj por segundo. 3 GHz ≈ 3.000 millones de ciclos/s. En cada ciclo el procesador puede avanzar en una tarea.
    • Núcleos (cores): unidades de procesamiento independientes dentro del CPU. Más núcleos = más tareas en paralelo.

    Módulo 4 · Sistema Binario y Digitalización

    Sistema binario: sistema de numeración en base 2 que usa solo dos dígitos: 0 y 1. Cada dígito se llama bit. Las computadoras lo usan porque sus transistores tienen dos estados eléctricos estables: con corriente (1) y sin corriente (0).

    • 1 bit = un 0 ó un 1.
    • 1 byte = 8 bits = 256 combinaciones posibles (2⁸). Alcanza para representar un carácter.

    Conversión binario → decimal (ejemplo con 8 bits)

    Peso del bit1286432168421
    Bits01000001

    01000001₂ = 64 + 1 = 65 en decimal = letra «A» en código ASCII (tabla que asigna un número a cada carácter: A=65, a=97, 0=48…).

    Digitalización

    Convertir señales analógicas (continuas: voz, luz, movimiento) en valores numéricos binarios. Pasos: 1) Muestrear (medir muchas veces por segundo) → 2) Cuantificar (asignar un número a cada muestra) → 3) Codificar (expresarlo en binario). Así se digitalizan audios, fotos y textos.
