Generación 01 📅 1991 – 2003 🌐 Nace en el CERN · Tim Berners-Lee

WEB 1.0 — La Red Pasiva

La web de solo lectura: el sitio publica, vos mirás. Nada de comentarios, nada de perfiles, nada de "compartir". Una biblioteca gigante donde nadie podía escribir en los libros.

01 Conceptos clave
DEFINICIÓN

“Read-Only Web”

La primera generación de sitios: comunicación unidireccional (sitio web ➔ usuario). El contenido lo creaba un único autor y casi nunca cambiaba.

📻 Como la radio: escuchás, pero no hablás
👤 ROL DEL USUARIO
  • ✅ Lee textos y mira imágenes
  • ✅ Sigue enlaces entre páginas
  • ✅ Imprime o guarda la información
  • ⛔ No comenta ni puntúa
  • ⛔ No publica ni edita contenido
Consumidor 100% pasivo
⚙️ CARACTERÍSTICAS TÉCNICAS
HTML básico<table> para maquetarGIFs animados <marquee>Sin bases de datos dinámicasFTP para subir archivos Módem 56k 🐢Libros de visita estáticos

Cada página era un archivo escrito a mano: el servidor solo lo entregaba, nunca procesaba datos del visitante.

🏛️ EJEMPLOS HISTÓRICOS
🖥️
El primer sitio web (1991)
Creado por Tim Berners-Lee en el CERN. Era puro texto con enlaces.
📚
Enciclopedias digitales estáticas
Como Encarta: el contenido venía "cerrado", nadie podía corregirlo.
🏘️
GeoCities y páginas personales
Los usuarios armaban su "barrio" con HTML, contadores de visitas y GIFs.
🗂️
Directorios como Yahoo!
Listados de sitios organizados a mano por editores humanos.

Generación 02 📅 2004 → hoy 📣 Término acuñado por Tim O'Reilly

WEB 2.0 — La Red Participativa

La web de lectura y escritura: la página deja de ser un folleto y se convierte en una conversación. Vos también publicás, comentás y compartís.

01 La ecuación de esta era
PRODUCTORcrea fotos, videos, textos
＋
CONSUMIDORmira, lee, escucha
＝
PROSUMIDORel usuario de la Web 2.0

Ya no hay "audiencia": hay participantes. Cada comentario, foto o video que subís alimenta la red.

02 Conceptos clave
📖 DEFINICIÓN

La Read-Write Web: plataformas donde el contenido lo generan los propios usuarios sobre páginas dinámicas conectadas a bases de datos. Nace formalmente como concepto en la conferencia de O'Reilly Media (2004).

BlogsWikisRedes socialesCompartir archivos
⚙️ TECNOLOGÍA QUE LO HIZO POSIBLE
  • 🗄️ Bases de datos detrás de cada sitio
  • ⚡ AJAX + JavaScript: las páginas se actualizan sin recargarse
  • ☁️ Servicios en la nube (documentos colaborativos)
  • 🔌 APIs: las plataformas se conectan entre sí
🌎 IMPACTO SOCIAL
  • 🤝 Trabajo colaborativo a escala global
  • 🗳️ Democratización: cualquiera puede publicar
  • 🧩 Inteligencia colectiva: muchos saben más que pocos
  • ⚠️ También: huella digital, desinformación y algoritmos que deciden qué ves → pensamiento crítico

WEB 3.0 — La Red Semántica

Leer + escribir + comprender. Las máquinas dejan de comparar texto y empiezan a entender el significado y el contexto de lo que pedís.

01 ¿Qué significa "semántica"?
El problema de la palabra "jaguar"
🐆
el animal felino
🚗
la marca de autos

La palabra es la misma: el significado depende del contexto. La Web 3.0 usa metadatos para que la máquina capte esa diferencia, igual que vos.

📖 DEFINICIÓN

La Read-Write-Execute Web: datos etiquetados con su significado para que las aplicaciones interpreten, relacionen y ejecuten acciones de forma interoperable. Suma además la descentralización (blockchain / Web3) y los datos abiertos enlazados.

MetadatosRDFOWLOntologíasBlockchainContratos inteligentes
✨ CARACTERÍSTICAS
  • 🔗 Interoperabilidad: los datos viajan entre aplicaciones
  • 🌐 Datos abiertos y enlazados entre bases globales
  • 🏛️ Descentralización: menos intermediarios
  • 🎯 Personalización extrema según contexto
  • 🔎 Búsquedas inteligentes por intención, no por palabra
🪄 EJEMPLOS
  • 🗣️ Asistentes que entienden tu contexto completo
  • 🧠 Wikidata / DBpedia: conocimiento enlazado del planeta
  • 📜 Contratos inteligentes que se ejecutan solos
  • 🎫 Identidad digital auto-soberana
Ejemplo de "triple" RDF (sujeto → predicado → objeto):
⟨Bariloche⟩ — esUna → ⟨Ciudad turística⟩

WEB 4.0 — La Red Inteligente

Ubicua, simbiótica y predictiva: la red está en todas partes, conversa con vos (y con las cosas) y se anticipa a tus necesidades gracias a la Inteligencia Artificial.

01 El motor de la Web 4.0
🗣️
PLN

Procesamiento de Lenguaje Natural: la máquina entiende lo que decís (¡con acento y todo!).

🧠
Deep Learning

Redes neuronales que aprenden de millones de datos y mejoran solas con la práctica.

🤖
Agentes autónomos

Programas que deciden y ejecutan tareas por vos: reservan, reprograman, avisan.

🌐
IoT

Objetos cotidianos con sensores conectados: heladeras, relojes, autos, aulas.

📖 DEFINICIÓN + DEBATE

La Web 4.0 describe una red que nos acompaña: comunicación máquina-máquina y máquina-humano en tiempo real, interfaces por voz, síntesis de voz e imagen y modelos predictivos. Ojo: es un concepto en construcción — algunos autores la llaman "web simbiótica" o "internet de las cosas inteligente".

⚙️ CARACTERÍSTICAS
  • 📡 Ubicuidad: la red está en todos lados (wearables, domótica)
  • 🔮 Predicción: anticipa necesidades con modelos de IA
  • 🗨️ Interacción natural: voz, gestos, contexto
  • 🤝 Simbiosis humano-máquina: decide con vos (o por vos)
