Módulo 1

Internet y Convergencia Tecnológica

🔄 ¿Qué es la Convergencia Tecnológica?

Es la integración de tecnologías que antes eran independientes (telecomunicaciones, informática, medios audiovisuales y entretenimiento) en un único dispositivo o plataforma digital. Tu smartphone es el campeón de la convergencia: es cámara 📷, tele 📺, teléfono 📞, consola 🎮 y computadora 💻… todo junto.

🌐 Internet: el gran unificador

La infraestructura global de Internet logró que la voz, los datos, la música y el video viajen por un mismo canal digital. Antes cada servicio tenía su red propia; hoy todo se transforma en datos que circulan por la red de redes.

📞 Voz💾 Datos🎵 Música🎬 Video →🌐 Internet

Módulo 2

Tecnología Web, Cloud Computing, Webstoring y Portable Apps

🧩

Tecnología Web

Lenguajes y protocolos que hacen posible la WWW: HTML (estructura), CSS (diseño), JavaScript (interacción) y HTTP (pedido/respuesta entre navegador y servidor).

☁️

Cloud Computing y SaaS

Software como Servicio: apps que se ejecutan en servidores remotos y usás desde el navegador, sin instalar nada. Ej: Google Docs, Canva, Spotify.

🗂️

Webstoring (guardado en la nube)

Guardar archivos en servidores de Internet (Drive, OneDrive, Dropbox) y abrirlos desde cualquier lugar con conexión. Chau pendrive olvidado. 😉

🔌

Software Portable

Programas que no requieren instalación: se ejecutan directo desde un pendrive en cualquier compu. ¡Ideal para netbooks sin permisos de administrador!

        ️ ¿Qué es un navegador?

        Es el software cliente que interpreta el código de las páginas web (HTML, CSS y JavaScript) y lo renderiza (dibuja) en tu pantalla. Sin navegador, la web sería solo texto y código crudo.

        Módulo 5

        Formato de una Dirección Electrónica Web (URL)

        🧬 ¿Qué es una URL?

        La URL (Uniform Resource Locator) es la “dirección postal” de un recurso en Internet. Cada parte cumple una función: el protocolo (https:// con cifrado SSL 🔒), el subdominio (www), el dominio (el nombre del sitio), el TLD (.com, .org, .edu, .gob), el código de país (.ar, .cl, .es) y la ruta interna (/carpeta/archivo.html).

        Módulo 6

        Correo Electrónico y Webmail

        📨 ¿Qué es el correo electrónico?

        Un servicio de red asincrónico (no hace falta que ambos estén conectados a la vez) para intercambiar mensajes digitales. Su dirección tiene 3 partes:

        nombre_usuario@servidor.com

        La arroba significa “en” (at): el usuario está en ese servidor.

        🌐 Webmail vs. Cliente local

        • Webmail ☁️: se usa desde el navegador, sin instalar nada (Gmail, Outlook.com, Yahoo). Ideal para la netbook del aula.
        • Cliente local 💻: programa instalado que descarga los correos (Thunderbird, Outlook de escritorio).

        🧠 Netiqueta (buenos modales digitales)

        • • Asunto claro y específico.
        • • Usá CCO para varios destinatarios y proteger su privacidad.
        • • NO escribas todo en MAYÚSCULAS: equivale a gritar.
        • • Desconfiá de adjuntos o enlaces sospechosos (phishing).
